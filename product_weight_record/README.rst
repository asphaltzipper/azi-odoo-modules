Product Weight Record
======================

This module allows users to record multiple weight entries in Odoo.

**Key Features:**

Record multiple weights readings for a product.  Optionally, specify a serial/lot number.

Usage
-----

1. Go to *Inventory > Configuration >
1. Establish weighing methods, and available accessories
1. Go to *Inventory > Products > Weight Records*.
2. Create or review individual weight records.
